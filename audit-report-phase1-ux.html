🎯 一句話結論
Phase 1 嘅限制冇致命傷玩家體驗。最痛係兩點：(1) 35-50 秒等故事生成中間冇 progress 反饋，用戶會懷疑 hung up；(2) 玩家輸入 action 之後睇唔到 state 數值點變 — narrative 完先 panel 跳，斷咗 cause-and-effect 感覺。呢兩點都係 quick win（半日工程），唔需要等 Phase 1.5 / Phase 2。

🔴2 個 CRITICAL UX issue

UX-01 生成故事 35-50 秒，冇 progress 反饋 Critical Constraint
症狀：用戶按「生成 + 即時開始」之後，得 1 個 spinner + 4 行靜態文字（「↳ AI 設計緊 state_schema...」永遠唔變）。35-50 秒對 first-time 用戶感覺超長 — 佢哋會懷疑系統 hung 咗、按到第二次、或者離開。
根本原因：我哋而家 server-side 一次過跑 4 parallel LLM calls，client 只見到 Server Action pending。client 唔知個 4 個 call 各自喺邊 stage。
Fix（半日 work）：將 4 parallel calls 改成 Server-Sent Events / streaming server action：每個 sub-call 完成就 stream「✅ 設計 dashboard 完成」「✅ 寫埋角色」反饋俾 client。用戶見到 step-by-step progress = 同樣 50 秒但感覺快 50%。
UX-02 State 數值更新同 narrative 斷咗連繫 Critical Logic flaw
症狀：用戶輸入「我送花俾林思雅」→ AI 串流敘事完 → side panel 突然跳數值（好感度 +12 etc.）。用戶睇唔到「呢個變化由我嗰個 action 引起」嘅 cause-and-effect feedback。對手平台（D&D Beyond，AI Dungeon 新版）都有 inline state delta toast。
根本原因：而家 turn endpoint 用 onFinish 寫 state delta 入 DB，client 之後 refreshState() fetch。整個 update 喺 stream 結束之後先發生，唔係 inline。
Fix（半日 work）：turn endpoint 在 stream 嘅 data chunks 之間插 state delta event (e.g. { type: 'state-delta', changes: [...] })。Client parse event → 即場顯示 toast「💗 林思雅好感度 +12」 + animate 個 ring。狀態變化變成 narrative 嘅一部分，玩家感到「我做嘅嘢有 impact」。

🟡6 個 Medium friction

Player journey friction 3 條
UX-03 冇 turn count / Act 進度感 Med Missing feature
症狀：玩 10 turn 之後用戶完全唔知自己「行咗幾遠」、「Act 1 完未」、「故事到中段定剛剛開頭」。冇 progression feedback = 冇成就感、冇 commit 感。
Fix：Header 加 turn count badge。State panel 頂部加「Act 1 / 4」slim indicator（從 bible.story_arc length + 玩到邊 act 推導）。Act 完成時加 toast「🎭 Act 1 完結 — 進入 Act 2」。
UX-04 冇 「New Story」 / 過去 playthroughs entry point Med Missing feature
症狀：用戶完成第一個故事之後，唯一返去其他故事嘅途徑 = 重新 navigate /stories/new 或者記住個 URL。/library 係 placeholder。/profile 都係 placeholder。Header「故事庫」 link 去 placeholder page。
Fix：/library 簡單實作 — list 用戶嘅 playthroughs (title + last_played_at + 「繼續」按鈕)。Header 嘅「故事庫」變 functional。Play screen header 加「+ 新故事」link。
UX-05 冇 preview / 唔可以重新 generate 故事 Med Missing feature
症狀：提交 prompt → AI 生成 → 自動 redirect /play/[id]。如果用戶睇完開場唔鍾意（NPC 不合心水、tone 唔啱），唯一辦法係重 prompt 一個全新故事。冇 preview / regenerate / edit 步驟。
Fix：生成完先去 /stories/[id]/preview，showcase title + opening + characters list + state panel。用戶按「開始玩」先建 playthrough；按「重新生成」就 retry (re-call schema generator)；按「微調 prompt」回到 form。
Logic / robustness 3 條
L-06 /turn endpoint 冇 rate limiting / debounce Med Logic risk
症狀：用戶 spam click「行動」可以同一時間 trigger 多個 parallel LLM call → race condition 寫入 turn_index UNIQUE constraint conflict → DB error。更壞：免費 tier 用戶 burn credits 多倍。
而家有的保護：Client 嘅 streaming state disable button。但 client-side 唔可信 — 用戶可以 devtools 強推。
Fix：Server 加 in-memory rate limit（5 req / minute per user）。Turn route 開始時 lock playthrough 寫一個 "in_progress" flag，stream 結束釋放；接下來 POST 見到 flag 就 reject 429。
L-07 Schema generation partial failure 嘅 cleanup 唔完整 Med Logic flaw
症狀：4 個 parallel calls 任何一個 fail → Promise.all rejects → schema-generator throw → actions.ts catch + 返錯誤俾用戶。但用戶見到嘅 error 係 generic "Story generation failed: ..."，唔知 fail 邊個 component。
Fix：用 Promise.allSettled + 確認所有 4 個 succeed 先繼續。任何一個 fail：retry 個 fail 嗰個 (max 1 retry)，全部 retry 完仲 fail 先 surface error 俾用戶 + 顯示 fail 邊個 part。
L-08 冇 LLM refusal 處理 Med Logic gap
症狀：Claude 對某啲 content (e.g. 過度暴力, illegal acts) 會 refuse 寫敘事，返一段 "I can't help with that..." instead of in-fiction response。我哋 turn endpoint 照當正常 response 處理 + 寫入 turn record → 玩家見到 AI 出戲嘅 refusal。
Fix：Phase 1.5 嘅 Director Model 會 pre-filter，避免 prompt 入到 Narrator。Phase 1 quick fix：onFinish 入 DB 之前 quick check text 開頭 keyword (e.g. "I can't", "I cannot help") + 回應一個 in-fiction generic「林思雅好似聽唔明你嘅意思，望住你...」當 fallback。

Cosmetic / Polish 3 條
L-16 "undo / rewind" 未做 Low v1.5 backlog
AI 寫錯嘢時無法 rewind。AI Dungeon 有「redo」「edit」按鈕。我哋目標係 ADR-008 嘅「永久後果」設計，所以 undo 要謹慎 — 可能只限「最後一個 turn」rewrite。v1.5 backlog item。
L-17 Streaming SSE 自製 parser fragile Low Polish
Play-client.tsx 自製 SSE parser，假設 AI SDK v6 protocol 唔變。Future SDK upgrade 可能 break。可改用 SDK 嘅 useChat hook（更 robust）但要 adapt 我哋嘅 API shape (action vs messages)。
L-18 Schema field key migration 冇處理 Low Edge case

📊 我嘅 take
