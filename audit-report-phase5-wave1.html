W1-AGG-H-02Rating UPDATE 改 story_id：舊 story aggregate 永遠唔重算 + 直接 browser exploitHigh

W1-RACE-M-01Reporter 帳號 delete-recreate 繞過 report dedupMedium
supabase/migrations/0009:83 (ON DELETE SET NULL) + 0010:182-184 (partial UNIQUE)
