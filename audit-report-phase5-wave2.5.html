W2.5-UX-M-01play-client double-consume of response body on 400/403/503 fall-throughMedium
web/src/app/[locale]/play/[playthroughId]/play-client.tsx:209-224
Wave 2.5 加 400 handler 讀 await res.json()。如果 body 唔 match action_blocked condition，fall-through 落底嘅 await res.text() — Fetch response single-consume → throw "body stream already read"。Real triggers: 「action must be 1-2000 chars」(route.ts:102) · 「invalid body」(route.ts:107) · 403「forbidden」(route.ts:123) · 任何 503 其他 error。同 pattern 適用 403 / 503 fall-through。
Fix：讀 body 一次 at top — const body = await res.json().catch(() => null); · 之後 key off body?.error per status。Drop 底嘅 await res.text() · fallback 用 JSON.stringify(body) 或 default 繁中 message。~10 LoC change.
W2.5-PERF-M-02fetchBoard serial alias iteration 喺 launch 加 ~600msMedium
web/src/app/[locale]/library/page.tsx:135-156
