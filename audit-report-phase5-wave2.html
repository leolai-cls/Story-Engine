Wave 2 嘅 multi-board library + CJK FTS + trending newcomer boost + 7 個 audit fold-in 都 land 咗，但 audit 揾到 5 個 launch-blocker：

（1）W2-GENRE-C-01 CRITICAL — Library page 嘅 6 個 genre carousel key 用英文（'romance', 'adventure', 'school', 'fantasy', 'sports', 'mystery'），但 schema-generator.ts:112 個 prompt 教 AI 出 CJK genre（「戀愛校園」、「古惑仔」、「玄幻冒險」）。永遠唔會 match。6 個 carousel 通通永久空白。Multi-board library 嘅核心功能 dead-on-arrival。

（2）W2-FILTER-H-02 HIGH — Search form select default value="" · `params.language ?? null` 唔 catch empty string · RPC 收到 where s.language = '' 永遠 0 結果。任何 user 按一次「搜尋」即見「冇結果」假象，library 表面壞晒。

（3）W2-UX-H-03 HIGH — Turn route 加咗 moderation block 返 400 JSON。Play-client 嘅 if-not-ok branch 唔 special-case 400，raw JSON 直接 render 落 ErrorCard。玩家見到 {"error":"action_blocked","message":"..."} 而唔係友善繁中。新安全 surface 第一次見人就 looks broken。

（5）W2-LAUNCH-H-05 HIGH — 配合 W2-GENRE-C-01：launch 時 library 顯示 = 1 個 熱門 row（1-3 個故事）+ 6 個空 genre 自動隱藏 + 1 個 最新（如有）。Compare 之前嘅 single-list UX 至少 feel populated。新 UX 反而 "wow this place is empty"。

Wave 1.5 嗰個 pattern 重演：fix shipped 但 audit 揾到新問題。今次焦點唔係 security 而係 UX completeness — Wave 2 嘅 features land 咗，但部分 land 喺 wrong place（English vs CJK key）/ wrong missing piece（empty string handling）。修嘅 LoC 細，但唔修就 launch demo dead。
