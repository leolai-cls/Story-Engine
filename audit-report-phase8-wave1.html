⛔ 結論：Phase 8 而家 SHIP = 100% broken + 法律 / 金錢風險

5 個 agent cross-reference 之後，發現呢個 wave 有 3 個獨立嘅 "feature 完全冇 work" bug + 4 個 "用戶錢 / 私隱受損" bug。手動驗證咗最關鍵嘅 3 個 CRIT，全部 confirmed。

  1. CRIT-01 · feature 完全唔 work：page.tsx select 個 column 叫錯名 (credits_balance vs DB 真係叫 credit_balance)，currentBalance 永遠係 0，modal CTA 永遠顯示「credits 不足」。冇 user 用得到。
  2. CRIT-02 · Revenue leak：Pro Quality 200-credit toggle 喺 client 出現但個 flag 從來冇 send 去 server。Pro user 揀 200 credit 但 server 只收 100。$0.17 GPT Image Pro 成本 vs 100 credit ≈ $0.05 retail = 我哋每張蝕錢。
  3. CRIT-03 · 私隱洩漏：scene-images Storage bucket 係 PUBLIC + storage path 用 {user.id}/{playthrough.id}/{turnIndex}-{Date.now()}.png。Adult 故事生成嘅成人圖係可以 enumerate（你 ID + 任何人 playthrough ID 都可以 brute force time）。
  4. CRIT-04 · Hard rule #4 violation：scene_image DB insert 失敗時，credits 已扣 + storage 已上傳，冇 auto-refund。用戶蝕錢、見唔到圖、冇任何 signal。
  5. CRIT-05 · Hard rule #6 violation：custom prompt 直接送去 image gen 冇 moderate。用戶可以寫任何 prompt 試 jailbreak provider。違反 CSAM pre-filter rule。
  6. CRIT-06 · i18n drift：5 個 server error code (storage_failed / playthrough_not_found / not_owner / turn_not_found / unauthorized) 喺 catalog 完全冇 entry → 用戶會見到 raw key 字串。
  7. CRIT-07 · stories.style_key 冇 DB CHECK constraint（hard rule #28 + #36 違反）— invalid style_key → modal 直接 crash。
  8. CRIT-08 · TTL cron 完全冇 implement — style_references / scene_images storage 永久累積，每月成本爆炸。

建議：立即 Wave 3 fix sweep · 4-6 個 task block，先 close 8 個 CRIT + 約 18 個 launch-blocking HIGH，再做 Audit Cycle 2 驗證 convergence。Hard rule #29「3-cycle pattern」適用 — 預計需要 2-3 個 audit cycle 至 0 CRIT/HIGH。
