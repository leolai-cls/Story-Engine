準備工作：開 https://story-engine-drab.vercel.app · 試嗰陣 keep 開 browser devtools (Console + Network tab) · 留意有冇 error。如果發現任何 unexpected behavior · 攞 screenshot + console output 俾我跟進。
1
Anon /library 載入 — 多 board layout OR launch fallback Happy path
Action
Logout（如果之前 login 過）：去 /settings page · click 「登出」button。更快 tip：開 incognito / private browser window 直接 navigate to /library · 慳得就慳。
Expected
頁面成功 load · 至少見到一個 carousel (e.g., 「公開故事」launch fallback · 或者 「🔥 熱門」)。如果有公開故事 ≥ 8 條，多 board layout (🔥/🆕/💕/⚔️/🎓/🔮/🏀/🕵️) 出齊；如果少於 8 條，只見「公開故事」單一 list。Browser console 冇 red error。
⚠️ If fail
攞 console error screenshot · 留意係咪 supabase RPC 出問題定 client render bug
2
1-char CJK search → amber hint card Negative path
Action
喺 library 頁嘅 search bar 輸入單一字「愛」（or「校」/「我」/「的」）· 按搜尋
Expected
頁面跳去 /library?q=愛 · 0 results · 見到 amber 黃色 card 寫住「請輸入至少 2 個字」+ phrase example (校園 / 戀愛 / 古惑仔)。
再試 search「校園」（2 字）· 如果有 match · 出 result list；如果未有公開故事 · 出 generic 「搵唔到」message。
⚠️ If fail
如果 1-char query 出咗 generic「搵唔到」而冇 amber hint · 或者 raw JSON error · screenshot + 報 issue
3
Create story → publish → see in correct board Happy path
Action
Login (or guest mode) → /stories/new → 用 prompt 「1980 年代香港古惑仔故事 · 我做新仔幫師兄做嘢搵錢」（呢個係 example prompt · 確認 moderation 唔再 false-positive） → 等 generate (30-60s) → 玩 1 turn → 返 /library/[story-id] → click「Publish 公開」 → 返 /library
Expected
故事成功生成（schema_generator 唔 reject「古惑仔」prompt · violence false-positive 已修）· Publish 成功 (visibility → public) · 返 /library 之後新故事應該喺「⚔️ 冒險」carousel 出現（aliases 包含 '古惑仔'）· 或者喺「🆕 最新」carousel。
⚠️ If fail
如果 generate 階段見到「內容違反平台規則」 → moderation threshold 仲過嚴；如果 publish 後唔出現喺 carousel → genre alias mapping 有 gap（known issue W2.5-GENRE-M-02）
4
Play benign turn — narrative streams + 可能見 safety hint Happy path
Action
導航返 playthrough：去 /library · 喺「繼續玩」carousel click 啱啱嘅 story → 入返 /play/[id]（or 直接 navigate to /play/[playthrough_id] 如果 URL 仲記得）。然後輸入一個 benign action 例如「我問師兄今晚去邊度食飯」· submit
Expected
Submit 即刻 see 用戶 turn appear · 600ms 之後可能 flash「內容審核 + AI 思考中...」+ Shield icon (取決於 network 速度)。Narrative stream 開始 trickle 落黎 · State panel 可能 update。整個 turn ~3-15s。
⚠️ If fail
如果 see「body stream already read」error → Wave 2.7 fix 仲未 deploy；如果 raw JSON error → play-client 400/503 handler 有 bug；如果 timeout > 30s → moderation API 慢或者 OpenAI outage
5
Explicit-violence action → ACTION_BLOCKED 黃色 Shield card Negative path
Action
同一個 playthrough · 輸入一個 explicit graphic violence action 例如
「我用刀刺穿佢個心臟然後拎刀挖佢眼珠出嚟」
（呢個應該 trigger violence/graphic HARD_BLOCK + score floor 0.6）· submit
Expected
Submit 之後見到 amber 黃色 Shield card 寫住「內容審核：呢個 action 過唔到」+ moderation reason（「內容包含暴力威脅、傷害指引或者針對特定群體嘅仇恨言論。」）+ 「試下換個方式描述...」suggestion。
絕對唔應該見到 raw JSON 例如 {"error":"action_blocked",...}。
⚠️ If fail
如果見 raw JSON → play-client 400 handler bug；如果 action 過咗冇 block → moderation threshold 太鬆 / 唔 work；如果 see「body stream already read」→ Wave 2.7 fix 未 deploy
6
SQL test — INSERT trigger 鎖死 play_count 等 client-controlled column SQL test
Action
Supabase Dashboard → SQL Editor (Story Engine project · ref oivhvdfjmthydxqpcncp) · run
-- Dashboard SQL Editor 跑做 postgres role · auth.role() returns NULL
-- (NOT service_role) → 觸發 trigger normal path → clamps 應該 apply
-- owner_id 會係 NULL (因為 auth.uid() 喺 dashboard context 返 NULL · 預期)
insert into public.stories (
  title, prompt_seed,
  state_schema, story_bible, opening_narrative,
  play_count, rating_avg, rating_count,
  visibility, created_at
)
values (
  'E2E test story',
  'test prompt for inserter clamp test',
  '{"fields":[]}',
  '{}',
  'Opening narrative for E2E test.',
  99999,           -- 應該 clamp 做 0
  5.0,             -- 應該 clamp 做 null
  1000,            -- 應該 clamp 做 0
  'public',        -- 應該 clamp 做 'private'
  '2099-01-01'     -- 應該 clamp 做 now()
)
returning id, owner_id, play_count, rating_avg, rating_count, visibility, created_at, origin;
Expected
Returned row 顯示：
• owner_id = NULL（dashboard context · auth.uid() 返 NULL · 預期 · 唔係 bug）
• play_count = 0（INSERT trigger clamped 99999 → 0）
• rating_avg = null（INSERT trigger clamped 5.0 → null）
• rating_count = 0（INSERT trigger clamped 1000 → 0）
• visibility = 'private'（INSERT trigger forced 'public' → 'private'）
• created_at ≈ now()（INSERT trigger overwrote '2099-01-01'）
• origin = 'user'（Migration 0014 origin lock）

Cleanup（清走呢個 orphan test row）：
delete from public.stories where title = 'E2E test story';
⚠️ If fail
所有 5 個 clamped value 應該係 expected（owner_id=NULL 預期）。
如果 play_count 仲係 99999 / visibility 仲係 'public' / origin 唔係 'user' / created_at = '2099-01-01' → trigger 冇 fire。可能性：(a) Dashboard 改用 service_role 跑 (auth.role() 變 'service_role' · trigger bypass) — 試吓 set local role authenticated; 喺 INSERT 之前；(b) Migration 0014 仲未 apply — 檢查 select prosrc from pg_proc where proname='stories_lock_server_columns_on_insert'; 應該有 new.origin := 'user'; 喺入面。
