2026-06-02 · 6 條搜尋線 · 32 個來源 · 85 條資訊收窄至 25 條重點 · 由 Claude 親手 vet 來源

一句結論：有人真係會離開 —— 但唔係為咗「記憶」或「速度」。佢哋為咗 現成角色（零門檻）、唔審查、多媒體、手機 而走。市場數據親手證實咗我哋個 pivot：記憶 + 速度係「衞生」唔係「賣點」。但同一份數據潑咗盆冷水 —— 留客係成個品類嘅死穴。

⚠️ 研究嘅自動「自我檢查」步驟撞咗系統 bug（每條資訊嘅核對 agent 都冇成功投票 → 全部被誤標「推翻」）。搜集到嘅來源同數字係真嘅，我已逐條人手核對來源質素；下面每個重點都標咗信心程度，並老實列出反方證據。

4成人 niche + 「中文圈藍海」裁決

成人 / 唔審查

  • 「唔審查」係已證實嘅出走 + 付費驅動力（Character.AI filter 迫走大批人）[7]
  • 大陸版連「擦邊」都要落架（MiniMax 早期嘅 Glow 疑因暗示性內容被下架）—— 需求真實但被審查壓住[10]
  • 大陸 app 受法規所限，合法上做唔到成人 → 結構性留俾你

中文圈藍海 — 半證實 ✓

  • 大陸市場大，但被審查綁死：做唔到成人、又賺得差（星野 1/13）

6引擎 / 體驗技術（較輕證據）

呢部分嘅來源較少（部分技術文 fetch 失敗），以下係行業普遍共識，當參考唔當定論：

  • 大 context 對短故事够用且更穩：一個連貫故事裝得落 context window 時，原文全文比「搵返片段（RAG）」更一致。RAG 主要喺跨好多文件 / 超長歷史先回本。
  • 「迷失喺中間」效應：context 太長時，model 容易忽略中段資訊 —— 即係一味塞長唔等於記得好。
  • 逐字串流大幅提升「感覺快」：就算總時間一樣，逐粒字浮出嚟主觀上快好多 —— 直接對應你成人模式 Grok「等成段先彈」嘅痛點。

7建議：先做乜、點收費

數據指向一個好清晰嘅次序（同我哋傾嘅「輕模式做主打」完全一致）：

1
唔審查成人 + 現成靚故事/角色（零門檻）
呢個係最強付費驅動 + 大陸大廠入唔到嘅結構性護城河。確保「揀個故事撳一下就玩」夠快夠順。
2
體驗層：插圖 + 手機原生 + 角色卡
贏 ChatGPT 嘅實際原因。圖一定要背景生成，唔阻出文。
3
留客機制：「有目標嘅故事」而唔係漫無目的傾偈
品類死穴係留客；分析師建議「畀佢一個目標 / 似遊戲」。呢個正路就係你個「深模式」嘅擲骰/支線/進度 —— 但要做到「賺到先使」，唔好成日開住拖慢。
4
記憶引擎：降級做後台「衞生」
唔好再當賣點宣傳、唔好成日開住燒錢拖慢。留返「故事玩到好長」先出手。

收費

訂閱係主流但轉化低（~1.5%）。真正肯畀錢嘅點係「解鎖唔審查 + 深度體驗」，唔係「更長記憶」。建議：免費策展故事拉人入嚟 → 成人 / 深模式收費。對齊返我哋傾嘅「輕=平=拉人、深=貴=Pro」。
