🎭 The Character Consistency Problem

Stable Diffusion / Flux / DALL-E / Imagen 全部喺同一個 prompt 內可以畫到一致角色 · 但跨 prompt 跨 generation 就會樣樣唔同。「林思雅」第一張圖係黑長髮鳳眼 · 第二張圖變紅短髮 · 第三張變混血 — 玩家 immersion 即時崩潰。

🔞 NSFW image gen UX (founder Q · 2026-05-28)

Founder question: 「allow user to gen nsfw image · 睇下要唔要加個掣定係嗰個對話係呢個模式咁就會 default nsfw mode」

建議: 跟 story content_rating · 唔加 per-image toggle。Cleanest UX · matches existing architecture · zero new state to manage.

Story stateUser stateImage gen 行為Provider routing

點解 NSFW follows story · 唔加 per-image toggle

  • Mental model 一致: 用戶喺 story creation 已經 declare 咗呢個故事係 adult-rated · 故事入面所有內容 (text turns + visualizations) 都跟同一個 rating 行為
  • 避免「inconsistent images in same story」: 用戶 SFW 故事突然 gen 一張 NSFW 圖 · UX 上 weird · 而且 character consistency 都會崩 (SFW portrait vs NSFW scene)
  • Per-image toggle 會無意間 trigger NSFW 喺 SFW story 用戶: 用戶手快 click 錯 toggle · 出咗 NSFW 圖喺 SFW 故事 · 然後 share → embarrassment
  • 已有 architecture carry: content_rating + adult_mode_enabled + KYC verified 三 layer gating 已經 ship (Phase 6 money tier · Migration 0009-0028) · image gen 沿用 zero new code
  • 用戶想 NSFW 圖嘅做法: 創 adult-rated story · 喺 adult-mode 入面 · 自然每張 scene image 都係 adult capable

⚠ 不過要 add: 「Visualize this turn」button disable 喺 adult-mode-off + adult story

  • Future model swap easier: when Gemini ships Imagen 4 or OpenAI ships GPT Image 3 · just change model_id string · zero new auth code
  • Failover: if Google Imagen 3 endpoint down · can switch to black-forest-labs/flux-pro-1.1 via same OpenRouter call · 5-line change

⚠ Risk inventory

🔴 Risk · CSAM / illegal imagery via image gen

Hard rule #6 嘅 image extension。Flux / Replicate 都有 built-in safety filter · 但 sexual/minors 都有可能 generate (depending on prompt phrasing). Mitigation:

  • Pre-flight: scene_prompt → OpenAI Moderation API check · 同 turn 用同樣 pipeline
  • Post-flight: 收到 image → 第二 moderation pass via Google SafeSearch / AWS Rekognition · cost $0.001/image
  • Adult mode locked stories · image gen 一律 reject if user adult_mode=off
  • Audit log: scene_images.prompt_text 永遠保留 · admin moderation queue 可以 retro-review

Cost: +$0.001/image moderation. Latency: +1-2s.

🟠 Risk · 「我嘅角色係我認識嘅人」 — real-person likeness

用戶 upload custom portrait (v1.5) · 可能 upload 真人 image · 然後 LoRA train 出真人替身 → privacy 災難 + 法律問題。Mitigation:

  • Custom upload only allowed v1.5 + face-detect reject (must be clearly illustrated · not photograph)
  • EULA explicit: characters must be original · no real-person likeness
  • Admin review flag for any reported "this looks like a real person" report

🟠 Risk · 一致性 drift · 玩家發現「呢個唔似上次嘅林思雅」

IP-Adapter 70-85% consistency 意味 15-30% 嘅圖會有 noticeable drift。Mitigation:

  • 每 gen 後玩家有「Re-generate」 button (cost 50% · 即 25-100 credits)
  • Pro Max LoRA tier (v1.5) 用戶可以 unlock 95%+ consistency · upsell hook
  • UI hint:「AI-generated · 細節可能會略有不同 · 唔合心意可以重 gen」

🟡 Risk · Replicate downtime / rate-limit

Replicate API 偶有 30-second downtime · 5xx 容易。Mitigation:

  • Failed gen 唔扣 credit (charge only on success · same pattern as turn)
  • Fal.ai backup pool · auto-fallback if Replicate 5xx ≥ 3 times in 1 minute
  • Queue + retry · max 3 attempts

🟡 Risk · Storage cost runaway

Supabase Storage $0.021 / GB / month。1024×576 PNG ~400 KB. 1k users × 10 images/month = 4 GB. 1 year cumulative 50 GB · ~$1/month negligible. 但 long-tail 5 years × 100k users = real cost。Mitigation:

  • Auto-archive after 6 months · move to Cloudflare R2 ($0.015/GB) or Backblaze ($0.006/GB)
  • Thumbnail (256×256 webp) inline · full image lazy-load
  • User-initiated delete kept simple · admin batch delete for abandoned accounts
