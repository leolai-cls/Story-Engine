🎯 Vision · 邊個故事都係一本可以視覺化嘅書

核心 user moment

玩家打到一個「靚 turn」（NPC 推開佢、Skill Check 大成功、角色第一次接吻）· 想留低做紀念 · 想 share 朋友 · 想當 phone wallpaper。今日 Kieio 只有文字。Phase 8 加上一個 「生成呢個 turn 嘅畫」按鈕 → 用戶花 credit 換到一張高質量插圖 / 漫畫面板 / wallpaper。

3 大商業價值：

  • 收錢：每張圖 ~$0.04-0.10 LLM cost · charge 50-200 credits ($0.50-2.00) · margin 80-95% — credit sink 比 turn cost 更猛
  • 護城河：競對 (AI Dungeon · Character.AI) 都係純文字 · 加圖即時 visible differentiator
  • 病毒擴散：玩家 share 漫畫面板到 IG / Threads / 小紅書 → 圖嘅底有「Kieio · 我做緊呢個故事」watermark + 故事 URL → marketing 0-CAC

🎭 The Character Consistency Problem

Stable Diffusion / Flux / DALL-E / Imagen 全部喺同一個 prompt 內可以畫到一致角色 · 但跨 prompt 跨 generation 就會樣樣唔同。「林思雅」第一張圖係黑長髮鳳眼 · 第二張圖變紅短髮 · 第三張變混血 — 玩家 immersion 即時崩潰。

Character sheet · per-character one-time generation

用戶創 story · schema-generator 出 NPC list · 我哋順便 trigger 一個「character portrait generation」:

  1. 從 character card 嘅 traits + voice_sample 抽 visual hints → LLM 寫一段「visual_description」（150-300 字 · 描述外表 · 衣著 · 標誌性特徵）
  2. 用 visual_description 生成 ONE 張 reference portrait (1024×1024 · 3/4 face shot · 中性背景)
  3. 存 Supabase Storage · 同 character row link
  4. 之後每個 scene gen · 拎呢個 portrait 做 IP-Adapter reference + visual_description 做 prompt suffix

Cost: portrait $0.04 × N characters · 平均 3-5 個 NPC = $0.12-0.20 / story · grain charge once at creation (e.g., 200 credits add-on)。

Style profile · per-story one-time

創 story 時 LLM 同時生成 style_profile (e.g.):

{
  "art_style": "Wong Kar-wai noir cinematography",
  "color_palette": "neon-lit, deep shadows, warm amber highlights",
  "era_aesthetic": "1980s Hong Kong street fashion",
  "medium": "oil painting · gritty texture · soft focus",
  "reference_artists": ["Christopher Doyle", "Wong Kar-wai"]
}

每 scene gen 都 append 入 prompt suffix。Visual cohesion 跨整個 story 維持。

Backend pipeline (per click)

// Step 1 · Detect characters from turn context (founder Q2)
characters_in_turn = detectCharactersFromTurn(turn.text, story.characters)
// Match NPC names mentioned + dialogue speakers · returns full character_ids

// Step 2 · Build scene prompt (founder Q4)
scene_prompt = userPromptOverride
  ?? await summarizeTurnForScene(turn.text, characters_in_turn)
// LLM-extracted: action / location / mood / NPCs in frame

// Step 3 · Lazy character sheet gen (founder Q1)
for (char of characters_in_turn) {
  if (!char.portrait_url) {
    char.portrait_url = await generateCharacterPortrait(char)
    // 1-time per character · stored in Supabase Storage
    // Cost: $0.04 charged to user (forewarn in modal)
  }
}

// Step 4 · Route to provider (founder Q3 + Q5)
provider = pickImageProvider(story, imageType, userTier)
// SFW illustration/wallpaper → Gemini Nano Banana
// SFW comic panel (needs text rendering) → GPT Image 2
// Adult-rated story → Grok Aurora

// Step 5 · Generate
image = await provider.generate({
  prompt: buildFinalPrompt(scene_prompt, characters_in_turn, story.style_profile),
  reference_images: characters_in_turn.map(c => c.portrait_url),
  aspect_ratio: aspectFor(imageType),  // 16:9 / 4:3 / 9:19.5
  text_overlay: imageType === 'comic' ? extractDialogue(turn) : null,
})

// Step 6 · Post-flight moderation (defense-in-depth)
moderationResult = await moderateImage(image)  // CSAM check
if (!moderationResult.allowed) {
  refundCredits(user, credit_charge)
  return { ok: false, code: 'moderation_blocked' }
}

// Step 7 · Store + bill
storage_url = await uploadToSupabase(image)
await applyCreditCharge(user.id, credit_charge, 'scene_image_gen')
await insertSceneImageRow({ playthrough_id, turn_index, storage_url, ... })

Provider routing logic

function pickImageProvider(story, imageType, userTier) {
  // Adult-rated story → Grok exclusively (only NSFW-permissive option)
  if (story.content_rating === 'adult') return 'xai-grok';

  // Comic panel needs text bubble · GPT Image 2 renders Chinese natively
  if (imageType === 'comic') {
    // Pro tier: premium GPT Image (high quality · $0.17) for better text fidelity
    // Standard tier: GPT Image low ($0.04) acceptable
    return 'openai-gpt-image';
  }

  // Default SFW illustration / wallpaper → Gemini Nano Banana (cheap · consistent)
  return 'google-gemini';
}

為咩呢 3 個 (vs 我之前嘅 Replicate Flux)

⚠ Risk inventory

🔴 Risk · CSAM / illegal imagery via image gen

Hard rule #6 嘅 image extension。Flux / Replicate 都有 built-in safety filter · 但 sexual/minors 都有可能 generate (depending on prompt phrasing). Mitigation:

  • Pre-flight: scene_prompt → OpenAI Moderation API check · 同 turn 用同樣 pipeline
  • Post-flight: 收到 image → 第二 moderation pass via Google SafeSearch / AWS Rekognition · cost $0.001/image
  • Adult mode locked stories · image gen 一律 reject if user adult_mode=off
  • Audit log: scene_images.prompt_text 永遠保留 · admin moderation queue 可以 retro-review

Cost: +$0.001/image moderation. Latency: +1-2s.

🟠 Risk · 「我嘅角色係我認識嘅人」 — real-person likeness

用戶 upload custom portrait (v1.5) · 可能 upload 真人 image · 然後 LoRA train 出真人替身 → privacy 災難 + 法律問題。Mitigation:

  • Custom upload only allowed v1.5 + face-detect reject (must be clearly illustrated · not photograph)
  • EULA explicit: characters must be original · no real-person likeness
  • Admin review flag for any reported "this looks like a real person" report

🟠 Risk · 一致性 drift · 玩家發現「呢個唔似上次嘅林思雅」

IP-Adapter 70-85% consistency 意味 15-30% 嘅圖會有 noticeable drift。Mitigation:

  • 每 gen 後玩家有「Re-generate」 button (cost 50% · 即 25-100 credits)
  • Pro Max LoRA tier (v1.5) 用戶可以 unlock 95%+ consistency · upsell hook
  • UI hint:「AI-generated · 細節可能會略有不同 · 唔合心意可以重 gen」

🟡 Risk · Replicate downtime / rate-limit

Replicate API 偶有 30-second downtime · 5xx 容易。Mitigation:

  • Failed gen 唔扣 credit (charge only on success · same pattern as turn)
  • Fal.ai backup pool · auto-fallback if Replicate 5xx ≥ 3 times in 1 minute
  • Queue + retry · max 3 attempts

🟡 Risk · Storage cost runaway

Supabase Storage $0.021 / GB / month。1024×576 PNG ~400 KB. 1k users × 10 images/month = 4 GB. 1 year cumulative 50 GB · ~$1/month negligible. 但 long-tail 5 years × 100k users = real cost。Mitigation:

  • Auto-archive after 6 months · move to Cloudflare R2 ($0.015/GB) or Backblaze ($0.006/GB)
  • Thumbnail (256×256 webp) inline · full image lazy-load
  • User-initiated delete kept simple · admin batch delete for abandoned accounts
