📜架構決定紀錄 (ADR)

每個重要決定一條，知道而家咁做嘅原因。

ADR-015 🌟 Orchestrator Pattern 正式 lock（用戶 architectural intuition） ✓ Accepted 2026-05-21
Decision: Turn pipeline 永遠採用 orchestrator pattern — 玩家輸入永遠先經過我哋後台（Next.js Route Handler）做框架 enforcement + 記憶 prep + Director 仲裁 + Skill Check，先至 call 外部 LLM API。玩家 prompt 冇辦法直接觸碰外部 LLM。
Context: 用戶獨立 intuition — 「call 正式嘅 api 之前我哋先 call 一個內部用嘅 api 去過濾同埋去做嗰個幾層框架嘅東西」。呢個係 industry-standard pattern（ChatGPT plugins / Perplexity RAG / Cursor agent 都係咁）。Formally lock 防止 architecture drift。
Consequences: Marginal cost ~5-15%/turn（Director cheap model + Moderation 免費）。Prompt caching 抵消大部分。記憶系統反而更強（智能 retrieval 而非 dump raw history）。玩家 prompt jailbreak 95%+ 攔截。可並行 moderation + memory + cache load。Latency target 5-7s/turn。
ADR-014 AI 記性引擎用 OpenAI Embeddings（at launch） ✓ Accepted 2026-05-21
Decision: 用 OpenAI text-embedding-3-small（$0.02/1M tokens）。Phase 2 開工前用 100 段中文 turn 做 A/B benchmark 比較 Cohere，差距明顯先 switch。
Context: 用戶揀 A。OpenAI 中文 OK，cost 幾乎 free at 我哋 scale。
Consequences: Embedding pipeline 簡單。如 Phase 2 benchmark 差，可 swap provider（重新 embed 歷史 turn）。Cost negligible。
ADR-013 違規過濾用 OpenAI Moderation API（at launch） ✓ Accepted 2026-05-21
Decision: Phase 1 trial 起用 OpenAI Moderation API（免費）做 CSAM + 違法內容 pre-filter。Phase 5 社群上線前 review 漏網率，決定升唔升 Hive（USD$50-200/月）。
Context: 用戶話「you decide」。揀 A 因為 free + cover 大部分 case。
Consequences: Moderation 成本 = $0。Edge case 漏網 risk 存在但可接受 at small scale。Phase 5 前必 review。CSAM 永遠用第三方 API。
ADR-012 Lorebook 同名 entity dedup 用 naive exact match ✓ Accepted 2026-05-21
Decision: Phase 2 用 naive exact-name match。「阿明」「陳家明」當兩個。Phase 5 後 upgrade embedding-based。
Context: 純技術（Claude auto-decided）。Business 影響有限。
Consequences: 快；early users 可能見重複 entity；upgrade 路徑清晰。
ADR-011 官方故事由 founder + Claude 自己創作（at launch） ✓ Accepted 2026-05-21
Decision: Phase 7 launch 嘅 5 條官方故事由 founder + Claude collaboration 創作，唔請外面 writer at launch。
Context: 用戶揀「me + you, can do it later」。Solo 方式更 lean，align founder vision。
Consequences: 唔需要 Phase 7 前準備 writer 合約 template。Author monetization defer 去 v1.5+。將來 author program 嘅版權安排（Q7）仲未 decide，但 launch 之前唔影響。
ADR-010 Launch HK + TW 同步 ✓ Accepted 2026-05-21
Decision: Public launch 同步 target HK + TW 兩個市場，唔做 sequential。
Context: 用戶揀 B。TW 市場大 4x，文字遊戲社群更活躍，同步加速 PMF。
Consequences: 官方故事要 HK + TW cultural diversity（唔可以全 HK setting）。Marketing budget day 1 split。Beta tester dual channel（HK 巴 + TW Dcard/PTT）。繁中 locale awareness（HK繁 vs TW繁 用字唔同）。PR 兩邊都要 plan。
ADR-009 預設訂價用 USD ✓ Accepted 2026-05-21
Decision: 所有 tier 用 USD ($9.99/$19.99/$49.99)。HK + TW 用戶都睇 USD。Stripe 自動 currency conversion at checkout。
Context: HK + TW 用戶 subscription 習慣睇 USD（Netflix, Notion, ChatGPT）。Multi-currency setup 複雜。
Consequences: Stripe 設置最簡單。Marketing 文案統一。Pricing page 加 "約 NT$X / HK$X" 幫助理解（display only，actual charge USD）。Multi-currency 推遲到 v2。
ADR-008 Bible 3-tier calibration（hard / soft / open） ✓ Accepted 2026-05-21
Decision: Story Bible 分 3 層 — Hard Locked (150-300字) / Soft Guided (300-500字) / Open (0字)。
Context: 用戶 raise — 太強框架會寫死故事，太鬆 = yes-man。要 calibrate。
Consequences: 故事弧 transition 用 condition 而非 turn count；NPC 紅線可被 in-game earned exception unlock；對白/場景/反應 100% Open layer。
ADR-007 3-layer API defense ✓ Accepted 2026-05-21
Decision: Bible enforcement 用 3 層 — system prompt priority + Director Model + tool calling structured output。
Context: 單靠 system prompt 95% 攔到但老練玩家可 jailbreak。
Consequences: 每 turn 兩個 LLM call（Director cheap + Narrator premium）。Prompt caching 抵消 Bible/Cards 大 system prompt 成本。
ADR-006 Narrative Integrity Engine ✓ Accepted 2026-05-21
Decision: 加 4 層 narrative integrity system 解決 "Yes-Man AI" 問題。MVP day 1 hard requirement。
Context: 業界 #2 churn 痛點 — AI 取悅玩家、NPC 冇靈魂、玩家暴走。
Consequences: DB 加 story_bible, story_characters, playthrough_character_states 同 turns 表 director/skill_check 欄位。Phase 1.5 加入。
ADR-005 4-layer memory system ✓ Accepted 2026-05-21
Decision: 4 層記憶 — Recent 20 turns + rolling summary + pgvector RAG + 自動 lorebook。
Context: 業界 #1 churn = AI 唔記得。Lorebook only（NovelAI 做法）唔夠。
Consequences: pgvector + OpenAI embedding。Background Edge Functions 做 summary + entity extraction。
ADR-004 Adult mode 用 LLM 隔離設計 ✓ Accepted 2026-05-21
Decision: 成人模式 opt-in + Stripe Identity + 開啟後 model picker 限 OpenRouter。Anthropic/OpenAI 永遠唔跑 NSFW。
Context: 大 model 公司 TOS 違規會 ban 整個 platform。
Consequences: OpenRouter 接入係 Phase 6 必須。Adult tier 限 Storyteller+。CSAM pre-filter 永遠 on。
ADR-003 多 LLM 用戶可揀 ✓ Accepted 2026-05-21
Decision: 用 Vercel AI SDK 統一接 Anthropic + OpenAI + Google + xAI + OpenRouter。Per-playthrough 揀 model。
Context: 用戶 explicitly want。唔同 model 有唔同 strength。
Consequences: Model registry 喺 DB（唔 hardcode）。每 model 有 credit_multiplier。Phase 3 implementation。
ADR-002 一個 engine handle 三個 mode ✓ Accepted 2026-05-21
Decision: 用戶創作 / 社群 / 官方 用同一個 engine。分別只係 origin field + owner_id。
Context: 三個 mode 本質都係 prompt-seeded continuation。
Consequences: MVP scope simpler。Library 模型統一。社群分享 = 改 visibility flag。
ADR-001 Tech stack lock ✓ Accepted 2026-05-21

📖 Glossary

📖術語表

我哋發明同使用嘅術語。新 session 可以 quick reference。

中文 / 業務術語

故事聖經 (Story Bible)
創作時 AI 生成嘅不變骨架，包含核心衝突、世界規則、故事弧、語調。分 Hard Locked / Soft Guided 兩層。每 turn 注入 context（prompt-cached）。
角色卡 (Character Card)
每個 NPC 嘅模板，包含性格、過去、目標、紅線、講嘢風格、發展弧。Story-level template，唔同 playthrough 共享但 state 獨立。
紅線 (Red Lines)
NPC 嘅 hard behavioral limits。觸發即 in-fiction 拒絕。可被 in-game earned exception unlock。
Earned Exception
玩家透過 in-game 行動（唔係 prompt）觸發 permanent_flag，解鎖某條紅線變鬆。
故事自適應介面
AI 為每個故事生成專屬 JSON Schema + render hints，前端 generic renderer 自動呈現相應 UI（戀愛 → 好感度環，D&D → HP/MP 條）。
Director (仲裁 AI)
每 turn 第一次 LLM call，用 cheap model 預先審核玩家行動，輸出 verdict 俾 Narrator。
Narrator (敘事 AI)
每 turn 第二次 LLM call，用玩家揀嘅 premium model 根據 Director verdict 寫敘事 + state delta。
Skill Check
Director 觸發嘅擲骰仲裁。(skill + d20) vs 難度。失敗有真實 state 後果。
狀態介面 (State Panel)
玩家 play 時側邊 panel，render current_state 跟 state_schema。
Lorebook
自動 / 手動建立嘅 entity 檔案（角色、地點、物品），相關 mentioned 時 always-on injection。

技術 / 架構術語

Playthrough
一個用戶玩一個 story 嘅獨立 instance。包含 current_state、turn history、character states。
Story
故事 template，包含 prompt seed、state schema、bible、characters、opening。Immutable to non-owners。
Turn
一個 user action + 一個 AI response 嘅 pair。儲存 text + state_delta + LLM metadata。
state_schema
JSON Schema 定義 playthrough state 結構。每個 field 有 render_hint。
state_delta
JSON Patch (RFC6902) 描述一個 turn 改變咗 state 邊啲 field。
render_hint
schema field metadata，告訴前端點 render（bar / progress_ring / inventory_list 等）。9 種 hint enum。
Credit
Internal pricing unit。1 credit ≈ $0.001 USD cost。Per-model multiplier 決定 LLM call 扣幾多。
Credit Ledger
Append-only 表，記錄每筆 credit 流入流出。Sum(deltas) == current balance（hard invariant）。
Permanent Flag
Playthrough 內永久 state marker。Director 用嚟 track earned exceptions / 重大事件。
Tier

業界 reference

RAG (Retrieval-Augmented Generation)
由 vector DB 搵相關過去內容塞入 prompt。我哋 memory layer 3 用。
pgvector
Postgres extension 提供 vector column + similarity search。Supabase 原生支援。
Prompt Caching
Claude / OpenAI / Gemini 支援，cache system prompt 前綴，重用時 input cost -90%。
Tool Calling / Function Calling
LLM API feature，AI 可輸出符合 JSON schema 嘅 structured data。
RLHF
Reinforcement Learning from Human Feedback — LLM 訓練階段，令 AI 跟 system 多過 user。
Jailbreak
用 prompt 技巧令 AI 忽略 system constraints。我哋 3-layer defense Layer 2/3 對付。
SFW / NSFW
Safe / Not Safe For Work。決定 content rating + 可用 model。
KYC
Know Your Customer — 年齡 / 身份驗證。Stripe Identity 做。
ADR
Architectural Decision Record — 一條 decision 嘅紀錄（context + decision + consequences）。
