P0A-MED-03 isChineseContent regex 漏咗 CJK Extension B/C/D（罕字 / 古字） MED
web/src/lib/ai/tier-router.ts:35

當前 regex：

const cjkCount = (nonWhitespace.match(/[一-鿿㐀-䶿]/g) ?? []).length;

覆蓋：

  • U+4E00–U+9FFF (Unified Ideographs · 常用) ✅
  • U+3400–U+4DBF (Extension A · 罕用) ✅
  • U+20000–U+2A6DF (Extension B · 古字 / 名字異體字) ❌
  • U+2A700–U+2B73F (Extension C) ❌
  • U+F900–U+FAFF (CJK Compatibility) ❌

Impact：用戶 prompt 入面有罕用字 / 古字 / 名字異體字（HK / TW 常見 e.g. 「峯」、「𠀪」）會 undercount · 變成 routes to English (Gemini Flash 而唔係 GLM-5.1)。30% 閾值幫到啲，但 edge case 仍會 mis-route。

修法：擴 regex：/[一-鿿㐀-䶿豈-﫿]|[\uD840-\uD87F][\uDC00-\uDFFF]/g（包 surrogate pair 處理 Extension B+）。或直接用 ICU script detection（如果有 import 預算）。
