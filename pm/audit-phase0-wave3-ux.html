P0BW3-MED-01 Legacy MODEL_PRICING bypass still tier-bypasses (residual Wave 2 issue) MED

credits.ts:498-528 · Wave 2 fix returns {allowed:true, reason:'legacy_model'} for any MODEL_PRICING-listed legacy id, but does NOT check the legacy model's min_tier. Free user can RLS-inject pt.llm_model='gpt-4o-mini' (originally min_tier='free' but no enforcement happens at this code path because MODELS[id] is undefined) → turn route accepts → providers.ts silent-falls-back to Sonnet 4.6 (real $0.060) → computeCredits charges at gpt-4o-mini rate (~$0.0023) = ~95% undercharge per turn.

Wave 2 commit message claimed legacy ids "still chargeable at correct rate" — accurate IF providers.ts also served them honestly, but providers.ts:54-57 silently falls back to Sonnet so the real cost diverges from the charge.

Cost impact today: 0 (no playthroughs use legacy ids · all 6 users default_tier='pro' · UPDATE policy permits column write but no current user has motive). Defense-in-depth concern only.
Mitigation paths: (a) column-protection trigger on playthroughs.llm_model (Wave 1 backlog item) · or (b) tighten bypass: when MODELS[id] undefined but MODEL_PRICING has it, additionally check pre-curation min_tier from a frozen legacy map. (a) is cleaner — RLS column restriction is the canonical fix per CLAUDE.md hard rule #15.

Defer to backlog: column-protection trigger already deferred from Wave 1. Document this is the same surface and they share the fix.

P0BW3-MED-02 createStoryFromPrompt language-routing edge: English prompt → Chinese story flips to English model MED

stories/new/actions.ts:160 · pickModelForTier(tierPref, seedText) passes user's seed prompt as language hint. isChineseContent uses 30% CJK threshold.

Edge case: "Write me a story about 高中校園 set in 1990s 香港" — 6 CJK chars / 46 non-whitespace = 13% → BELOW 30% threshold → English routing (Gemini Flash for Standard · GPT-5.4 for Pro). But the story narrative will be 中文 (user mentioned 香港 setting + 高中). Result: Chinese-themed story narrated by English-leaning model.

Mitigation options:
  • Lower threshold to 15% for prompt-language detection (less strict than narrative-language detection)
  • Look at the LLM-generated story.language field (set by createStoryFromPrompt's first schema-gen call) and re-route subsequent turns based on that
  • Add story.language as a stored hint and pass it to turn route's pickModelForTier (likely cleanest long-term)
Today: mid-Chinese English prompts are an edge case (not the common pattern). 繁中-first market means most prompts will be 100% Chinese (auto-detected) or 100% English (auto-detected). Defer.
