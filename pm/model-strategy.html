🤖 Model 策略

10 個 model 太多 · 收返做 5 個 curated

用戶唔需要喺 10 個 model 之間揀。Research benchmark + 競爭對手 pattern · 建議 curated 5 個 model + 1 個 director · 同時減 5 個 provider integration 到 2 個。

🎯 一句總結
而家：10 個 model · 5 個 provider (Anthropic + OpenAI + Google + xAI + Meta)
v2：5 個 curated model · 2 個 provider (Anthropic direct + OpenRouter for NSFW + 1 long-context alt)
原因：Claude (Sonnet/Opus) 喺 narrative + 中文寫作 benchmark 一面倒贏 · 其他 model 入嚟只係增加 paralysis 同 maintenance 負擔
UX win：用戶唔再 stuck 喺「揀邊個 model」· 預設係**正確答案** · 進階用戶仍可改
Ops win：少 5 個 integration · 少 5 個 pricing config · 少 5 個 model version 要 track

🛡️Vendor risk mitigation

咁少 model · 萬一 Anthropic outage · 點?

4/5 model 都係 Anthropic · single-point-of-failure 風險。Mitigation 計劃：
🔄
Auto-fallback to Gemini
Anthropic 429 / 503 / timeout → 自動 retry on Gemini 3.1 Pro · 用戶唔察覺 model 換咗 · 故事繼續。記錄 metric · 月度檢視 Anthropic SLA。
📅
Status page subscription
Anthropic status page RSS → Slack/email alert · 主動知 incident · 提前 warn 用戶。每年 99.5%+ uptime SLA · ~3 hour/month downtime ceiling。

🚀實施 (~10 分鐘)

點落地呢個 simplification
  1. Edit web/src/lib/ai/models.ts · 移除 5 個 model entry (GPT-4o · GPT-4o mini · Gemini 3.5 Flash · Grok 2 · Grok 2 Mini)
  2. Edit web/src/lib/billing/credits.ts · MODEL_PRICING 對應 5 個 entry remove
  3. Verify model picker UI · 自動 reflect catalog change (UI iterates MODELS object)
  4. Update DECISIONS.md · 加 ADR-018: 5-model curated strategy · 原因
  5. Migration check · 任何 user 嘅 default_model 設咗 drop 嘅 model → 自動 reset 去 Sonnet 4.6 (next login migrate trigger)
  6. Auto-fallback wrapper · 加喺 lib/ai/providers.ts · Anthropic call fail → Gemini fallback (~30 min)
