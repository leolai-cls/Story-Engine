NPC L3 流程 (高層次)

1️⃣
Director run
既有流程不變。Director 輸出 verdict + memory_hints + npc_updates (active NPC list)
2️⃣
Verdict check
如果 verdict === "reject" · SKIP NPC L3 (省錢 + narrative integrity · F-04 mitigation)
3️⃣
Tier + flag check
只 run L3 when: Storyteller tier + playthrough.npc_l3_enabled === true + active NPC count > 0
4️⃣
並行 NPC agents
For each active NPC (max 3): parallel Haiku call · own prompt + POV memories + others' L2 visible state · output inner_thought + intent + reasoning_trace
5️⃣
Inject into Narrator
N 個 NPC outputs → 整理成「NPC Inner Streams」block → 加入 Narrator dynamic system prompt · 用 [INTERNAL · DO NOT QUOTE] wrapper
6️⃣
After-block persist
Narrator 開始 stream 之後 · after() block 寫 inner_thoughts 到 DB · 同時 embed for future retrieval

Q3. Credit charge per NPC L3 call
(a) 3 credits ← 我推介 · 配合 real cost ~$0.003 × 2× markup × 600 rate ≈ 3.4 · round down to 3
(b) 2 credits · cheaper · more accessible
(c) 5 credits · premium pricing · margin ↑
Q4. Default ON 定 opt-in?
(a) Default ON for 新 Storyteller playthroughs · UI toggle prominent ← 我推介 · 即時感受到 differentiation · 用戶可以即刻 opt-out
(b) Opt-in only · discoverability problem · feature 可能 never used
(c) Hybrid: 第一個 Storyteller playthrough auto-ON · 之後新 playthrough 跟用戶上次嘅 preference
Q5. Ship 時機
(a) NOW (Session 13) · 趁 Phase 1 architecture 仲熱 ← 我推介 · Director npc_updates 已經 emit · trivial 接入
(b) 等 Money tier (Phase 4 Stripe) 上線之後先做 · 確保 Storyteller subscription 可以買到 feature 先 ship
