🔒Quota enforcement (簡化 vs v3.0)

移除 Pro turn cap · 只剩 L3 Agent 一個 counter

🗃️
DB schema (v3.1 簡化)
新 column on profiles:
• agent_calls_used_this_month integer default 0
• quota_reset_at timestamptz default now()

移除咗: pro_turns_used_this_month (v3.0 有 · v3.1 用唔住)
⏰
Monthly reset
Cron 日跑檢查 · now() - quota_reset_at > 30 日 AND tier is Standard · reset agent counter + update timestamp。Pro tier 完全 ignore (always-allowed)。Lazy fallback: turn route 同樣會 check 自動 reset · 防 cron miss。
🎭
L3 Agent gate (唯一 quota)
Before each NPC L3 agent call · Standard tier user check agent_calls_used_this_month + activeNpcCount <= 80。Exceeded → 靜靜 skip L3 (degraded narration · 唔扣 credit)。Pro tier 跳過呢個 check。
📊
UI surface
Settings 頁: 「呢個月 NPC L3 Agent: 42 / 80 calls」progress bar (Standard tier)
Memory Journal NPC Inner Voices tab: 「Standard tier · 仲剩 38 個 agent call」
Hit cap: 「L3 額度用晒 · 升 Pro 解鎖無限」+ one-click checkout
✅ 簡化 vs v3.0: 一個 counter (Agent) 而唔係兩個 (Pro + Agent)。Less code · less audit surface · less user confusion。

📌Edge cases + decisions (v3.1 locked)

Q: Standard 用戶月底 L3 quota 用晒 + 充值 top-up?
L3 quota 不變。Top-up 只加 credit · 唔 reset Agent counter。Standard 要 unlimited L3 嘅唯一方法 = 升 Pro。設計保持 L3 作為 Pro tier 嘅核心 differentiator。
Q: Pro 用戶 downgrade 至 Standard mid-month?
Stripe webhook customer.subscription.updated 處理。新 tier 立即生效 · existing credit_balance 保留 · L3 Agent quota counter 即時生效 (用戶可能即見到 "80/80 quota exhausted" if 之前 Pro 用爆 L3)。Pro Max model + Adult mode 同樣即時 lock。
Q: Free 用戶用晒 daily refresh credit 想加快?
Yes · 可以買 top-up。Top-up 任何 tier 都可以買 (包括 Free)。買咗 5k pack 就 credit_balance +5,000 · 但仍然 Free tier (沒有 Pro/L3/Pro Max access)。要解鎖功能必須 subscribe。
Q: Free 用戶 stockpile daily credits 然後一個月 burst 一次?
Cap free tier credit_balance at 3,000 (60 日 daily refresh worth)。Refresh cron 唔加 credit if balance ≥ 3,000。防止 stockpiling abuse · 同時容許 occasional binge play (60 days = 約 60 turn 一次過)。
Q: 舊有 Adventurer ($9.99) / Storyteller ($19.99) / Legend ($49.99) 用戶?
Migration 0029 backfill mapping:
• adventurer → standard (same price · 多咗 80 L3 quota; 冇咗 30 Pro cap)
• storyteller → pro (same features · same price · no change)
• legend → pro (price 由 $49.99 → $19.99 · Stripe credit balance refund difference for current period)
Email 通知 existing users · honor existing billing period。
Q: Image generation · NovelAI / AID 都有 · 我哋幾時加?
Phase 8+ roadmap。Launch 時 pricing page 加 footnote 「Cover image generation · Phase 8 嚟緊 (預計 launch 後 2-3 個月)」。對齊用戶 expectation · 唔承認 gap。Provider candidates: Fal.ai (cheap · fast) · Replicate (familiar API) · Together AI (中文 friendly)。
