懷疑派創投

投票前我講最尖嗰句：你哋成個團隊呢一年燒咗最多力嘅嘢（記憶引擎、角色靈魂、GM 仲裁、NPC 各自諗），市場研究啱啱證明咗係「用戶唔肯畀錢」嗰類。而真正有人畀錢嗰兩樣（唔審查、零門檻現成角色），你哋一樣未真正 ship。呢個錯配本身就係我最大嘅 concern。

P1【輕模式做主打】支持，而且係救命。你個產品而家輸俾 ChatGPT，唔係因為 ChatGPT 叻，係因為你自己加咗五層工序拖慢又整壞一致性 —— 你親手 de-feature 咗自己。砍走 GM 仲裁、逐字串流、全文俾佢睇，呢個唔係妥協，係止血。Character.AI 後台冇你複雜，但停留時間係 ChatGPT 三倍，證明「快+順+角色一致」先係留客貨幣。

P2【護城河重定位】有條件支持。方向啱（體驗層+唔審查+中文圈），但要老實：呢三樣冇一樣係「硬」護城河。唔審查係監管套利（隨時被支付商/法律 KO）、策展靚故事係營運壁壘（可抄）、中文圈係領先優勢非護城河。我接受你 reframe，但唔好呃自己呢度有「對手要 6-12 個月先抄到」嘅嘢。

P3【兩模式架構】反對（住先）。你而家連輕核心都未 ship 順，就講埋深模式分支 = 過早複雜化，正正係令你今日變慢嘅同一個病。深模式留喺 backlog，等輕模式有留存數據先講。

P4【似遊戲有目標】有條件支持。呢個可能係你真正未被驗證嘅差異化（「互動故事」vs 純陪伴），方向比記憶引擎值博。但未經市場證明，要當實驗、細範圍試，唔好當地基。

P5【Go/No-Go】有條件 Go（細注、設止損）。品類下載插水 65%、轉化 1.5%、solo dev 押成人法律+支付風險 —— 唔係一盤我會大注 lead 嘅生意。但沉沒成本已建好、邊際成本低、唔審查+中文圈確有未被服務嘅縫。當係一個低燒錢嘅試探注，3 個月內見唔到留存就轉或者收。

最毒嗰條我照答：當大 model 越強，你會唔會只係個快被碾嘅殼？會 —— 如果護城河係「記憶/智能」。所以 P2 reframe 反而救你：你嘅殼要建喺 model 唔會幫你解決嘅嘢（策展內容、社群、唔審查、中文圈分發、品牌），呢啲 model 變強都唔會自動送俾用戶。

增長 / 產品負責人

作為增長/產品負責人，我淨係問一條問題：新用戶頭一分鐘有冇被勾住，第 7 日點解會返嚟。用呢把尺睇 5 個議案。

P1（輕模式做主打）：我最支持呢個。研究擺明「更快回覆/更長記憶」唔係賣點，但呢度有個關鍵分別 —— 速度唔係賣點，但慢係殺手。對手 2 秒回，你每回合等成分鐘（成人模式仲要等成段先彈），呢個直接謀殺第一分鐘嘅 hook。第一回合慢過 10 秒，七成人走咗，根本未到「記性好唔好」呢個層次。砍走 GM 仲裁、逐字串流，係救命，唔係優化。

P2（護城河重定位）：支持。但要講白 —— 你嘅護城河其實係「現成、零門檻、唔審查、靚故事」呢個入場體驗，唔係後台記憶引擎。研究已經話畀你聽冇人為「記性」畀錢。我見過太多 team 死喺度：用半年起一個玩家三回合根本感受唔到嘅後台，攞嚟做差異化。記憶做差會輸，做好都唔會贏 —— 應該當衞生，唔係當賣點。

P3（兩模式架構）：有條件支持，但我最警惕呢個。每加一個「模式」就係加一層複雜度同上手摩擦。如果「深模式」係玩家自己撳、或者你偷偷喺後台跑，OK；但如果係要玩家理解「我而家係輕定深」，就會分散注意力、拖慢、製造唔一致。我只接受「玩家無感、系統自動」嘅版本。

P4（似遊戲嘅目標留客）：強烈支持，呢個係我最睇好嘅留客引擎。純陪伴傾偈冇 retention hook，但「有目標、有進度、有下一步」係經典 D1/D7 引擎 —— 玩家返嚟係因為「我上次差啲就到」。呢個比記憶引擎更能解決品類死穴。

P5（Go/No-Go）：有條件 Go。品類下載插水 65%、轉化 1.5%，但呢啲數係「純陪伴」嘅數；你有兩張別人冇嘅牌（唔審查成人+中文圈+似遊戲目標）。條件係：先用最低成本驗證「會唔會有人返嚟」，唔好未證明留存就燒錢起 feature。

我最關心嘅事：而家連一個乾淨嘅第一分鐘 demo 都未有。速度問題唔修好，其他全部討論都係空談 —— 因為玩家根本捱唔到睇到你嘅好。

技術架構師

作為技術架構師，我嘅判斷係：呢 5 個議案最值錢嘅地方，係佢哋幫你停止燒錢喺一個「用戶根本唔肯為佢畀錢」嘅後台，而唔係叫你 launch 一個新功能。

P1（輕模式做主打） —— 技術上 100% 做到，而且係你而家最該做嘅嘢。你個 pipeline 文件白紙黑字寫住現狀係「2 個 model call（Director + Narrator）」，目標係「1 個」。砍 Director、審查同抽狀態搬去背景（你 code 已經用緊呢個 pattern），每回合慢一半、平一半、drift 即刻收窄 —— 因為 drift 嘅最大來源就係兩個 model 各自詮釋。呢個係真簡化，唔係換個方式繼續複雜。

P2（護城河重定位） —— 同意，但要講清楚：唔係叫你拆走記憶引擎，而係唔好再為佢做到爆。你已經建咗信念圖譜、沉澱張力、4 層記憶 —— 呢啲係「做差會輸、做好都唔會贏」嘅衞生工序，研究亦印證「更長記憶」賣唔到錢。降做後台、唔再投資，啱。

P3（兩模式架構） —— 最危險嘅一個。「輕核心+深 opt-in」聽落靚，但對一個 solo dev，呢個係換個方式繼續複雜：你要同時養兩條 pipeline、兩套成本模型、兩套 bug 面，永遠 2x 維護。請唔好整個對等嘅「深模式」層，只保留可選單一加料（例如某類故事先開 NPC 各自諗），而且預設全關。

P4（似遊戲留客） —— 平台你已經有（故事自生成 mechanics / 擲骰），所以呢個係內容同設計問題，唔係架構問題。低成本、對留存有真槓桿，支持，但唔好當技術里程碑。

P5（Go/No-Go） —— 有條件 Go。品類下載插水 65%、轉化 1.5% 係真陰影，但你嘅技術底子已經 launch-ready（Stripe/驗證/多語全完），沉沒成本已付。唯一真技術紅旗 = 成人模式靠 Grok，而 CrazyRouter 條線係「成段寫晒先彈」唔串流，等成分鐘 —— 呢個你自己 model 揀唔到、改唔到，係供應商層問題。要 Go 嘅前提係先確認有冇串流得到嘅 uncensored model 替代，否則你最賺錢嗰個模式（成人）體驗最差。

AI 角色扮演領域專家

核實完技術前提：診斷報告同架構文件確認咗，成人模式真係每回合三個 model 串住（Haiku GM → Grok Narrator → 背景），Grok 經供應商係 buffered 唔逐字串流，而 GM 判斷過敏 + pushback 提示變死 script 係真實後台數據實證，唔係創辦人錯覺。呢啲坐實咗 P1 嘅迫切性。

核心判斷：單靠「唔審查成人」係護城河，但係一條淺護城河。Character.AI 趕客 → Janitor 接收呢個遷徙係真，需求係硬嘅；但 Janitor 本身就證明咗呢條河有幾淺 —— 佢用 BYOK（自己駁 model）、體驗粗糙，照樣食到大批人，因為用戶要嘅唔係「好體驗」，係「無人管我」。即係話「唔審查」本身唔會 lock 住人，佢只係入場券。中文圈呢張入場券有區域+語言護城（大陸大廠法律上做唔到成人，Talkie vs 星野 13 倍收入差距已證），所以你嘅真‧護城河 = 唔審查 × 中文圈 × 過得去嘅體驗三者疊埋，任何單一條都唔夠。

真正 retention 機制（領域實證）：唔係記憶、唔係速度。係（1）情感依附 —— 用戶同一個角色/世界建立關係，呢個係 25 分鐘 vs 8 分鐘嘅來源；（2）零摩擦重入 —— 撳就玩、秒回、手機，Character.AI 嘅 2 秒回覆係上癮引擎；（3）色情作為原始留存（殘酷但真）。你個產品而家三樣都輸：載入慢殺（2）、GM script 化殺（1 嘅沉浸）、品類本身（3）你有但被慢同 drift 拖累。所以致命傷唔係策略，係執行 —— 產品而家比 ChatGPT 差，呢個觀察我同意。

逐案：P1 啱大方向但要 reframe —— 慢嘅主因唔淨係 GM 仲裁，係 Grok buffered 唔串流，就算砍晒 GM，成人回合一樣等成分鐘，所以 P1 必須綁定「換可串流 model 或前端假串流」一齊做。P2 我強烈支持：將記憶/角色靈魂由「護城河 #1」降做衞生係今日最重要嘅認知矯正。P3 有條件支持但警告：兩模式 = 兩條 codepath，solo dev 維護地獄，深模式應該係「同一輕核心 + 背景非阻塞增強」唔係第二條同步管線。P4「似遊戲有目標」係品類續命真藥（陪伴 app 集體插水正正因為漫無目的），但成人向用戶嘅「目標」唔係支線任務係關係推進，要對。P5 我畀有條件 Go：需求真、區域護城真，但執行未到 ChatGPT 水平之前唔好諗錢。

中文圈市場 + 文化專家

收費模型我只信一個企得住：訂閱保底 + 成人/重度玩法用 credits 計量，絕不 all-you-can-eat。成人用 Grok 跑長 context，一個重度用戶月燒輕易 $8-15 成本，你訂閱 $9.99 做一個蝕一個，呢個係數學唔係意見。輕模式 P1 砍走 GM 同多餘 call，每回合成本跌 60-70%，同時救體驗同毛利，係五個議案入面唯一「免費午餐」。P3 深模式只可以做 Pro 訂閱內嘅 credits 消耗項。一句總結：體驗層（快、順、串流）決定有冇人留；計量式定價決定留得住嘅人賺唔賺到錢。兩者缺一，呢盤都唔成立。

最終投票
P1支持砍 GM + 多餘 call 令每回合成本跌 60-70%，同時救體驗同毛利，五案中唯一免費午餐
P2支持記憶/靈魂市場已證冇人單獨畀錢，降做衞生係對的，但停止過度投資、唔好拆走
P3有條件深模式只准做 Pro 內 credits 消耗項，嚴禁開獨立收費層重蹈 Pro Max 覆轍
P4有條件似遊戲目標成本高且服務轉化最低嘅免費群，當小範圍實驗用留存 gate，唔可當地基押
P5有條件Go空隙真但屬細注試探，硬前提係成人 credits 計量 + per-user 成本量度先拍板定價
最大隱憂：重度成人用戶 Grok 跑長 context 單人月成本可超訂閱價，unlimited 必做一個蝕一個，計量式定價唔到位呢盤數學上唔成立
