關 Deployment Protection（令 site public）
~1 分鐘

而家 access deployment 嗰陣 Vercel 要 auth — 你嘅 marketing site 應該係 public，等遊客可以見到。

  1. 打開 project Deployment Protection settings
  2. "Vercel Authentication" 預設可能係 "Standard Protection" 或 "All Deployments"
  3. 改去 "Only Preview Deployments" 或者 "Disabled"
    • Only Preview Deployments — Production 公開，Preview deploys 仍受 auth 保護（推薦）
    • Disabled — 完全公開（如果你會手動分享 preview URL 俾 beta tester）
  4. 按 "Save"
2
Add Environment Variables
~3 分鐘

而家 deploy 入面冇 Supabase env vars → runtime 會 crash。Paste 落 Vercel：

  1. 打開 project Environment Variables
  2. 每個 variable 都揀 "All Environments"（Production / Preview / Development 全部）
  3. 由你本地 web/.env.local 嘅 value 直接 copy
Key從邊度 copyScope
NEXT_PUBLIC_SUPABASE_URL 由 web/.env.local copy（https://oivhvdfjmthydxqpcncp.supabase.co） All
NEXT_PUBLIC_SUPABASE_ANON_KEY 由 web/.env.local copy（eyJhbGc... 嗰段） All
SUPABASE_SERVICE_ROLE_KEY 由 web/.env.local copy（service role eyJhbGc...） Prod
NEXT_PUBLIC_SITE_URL 暫時用 https://story-engine-tweenr.vercel.app（或者你之後嘅 custom domain） All
⚠️ 安全：SUPABASE_SERVICE_ROLE_KEY 絕密，可以 bypass 所有 RLS。Vercel 上面只 set "Production" scope（唔 share 落 Preview 因為 preview URL 可能 leak）。

4 個都 add 完，按 "Save"。Vercel 會建議 redeploy — 你 next push 會自動拎新 env vars，或者你可以喺 Deployments tab 揀最新嗰個按 "Redeploy"。
